# Digital Forensics Essays & Research

Deze repository bevat een selectie van essays en korte onderzoeksopdrachten die ik heb uitgevoerd op het gebied van Digital Forensics.

De documenten zijn geschreven tijdens mijn Minor Digital Forensics en mijn verdere studie. De onderzoeken van technische forensische analyse tot ethische, juridische en methodologische vraagstukken.

## Onderwerpen

### EXT4 Essay

Onderzoek naar bestandssystemen en hun forensische waarde, met aandacht voor onder andere:

- EXT4
- NTFS
- FAT32
- APFS
- metadata en timestamps
- deleted file recovery
- TestDisk
- PhotoRec
- Windows File Recovery

### Ethiek Essay

Analyse van ethische vraagstukken binnen digitaal forensisch onderzoek, waaronder:

- objectiviteit
- vertrouwelijkheid
- integriteit
- compliance
- privacy
- proportionaliteit
- monitoring van medewerkers
